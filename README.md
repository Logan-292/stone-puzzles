# Каменные скрижали: головоломки

Модуль для **Foundry VTT v14**: мастер даёт игрокам решать головоломки прямо в игре. Оформление: каменные таблички. Рассчитан на **D&D 5e (2024)**, но все головоломки работают и в других системах; от системы зависит только выбор бонуса в бросках.

## Головоломки

| Тип | Суть |
|---|---|
| **Радиальные кольца** | Ваша картинка режется на концентрические кольца, игроки вращают их до сборки. Первое верно поставленное кольцо фиксируется. |
| **Шифр** | Замена знаков (подбор букв с частотами) или круг Цезаря. Опциональный лимит попыток. |
| **Криптекс** | Колёса с буквами (кириллица, латиница, цифры или свой набор). Первые две верные буквы фиксируются. |
| **Пропущенное слово** | Предложение с пропусками `[слово]` / `[слово\|синоним]`, выбор из списка или свободный ввод. Опциональный лимит попыток. |
| **Арканый замок** | Нужно нажать руны на круге в заданном порядке. Ошибка гасит цепочку, можно включить заклинивание. |
| **Взлом замка** | Игрок выбирает позицию отмычки, а бросок персонажа (Ловкость рук / воровские инструменты) даёт точные подсказки. Ошибки изнашивают отмычки. |
| **Пары из картинок** | Мастер составляет пары из своих картинок и/или подписей (2–8). Игроки соединяют подходящие. Опциональный лимит попыток. |
| **Ловушка с рычагами** | Рычаги переключают огни, схема случайна и всегда решаема. Каждое движение будит ловушку. Бросок Расследования раскрывает действие рычага. |
| **Тень и свет** | Луч идёт слева, игроки поворачивают зеркала, чтобы он дошёл до руны. Есть лишние зеркала и каменные блоки. Схема всегда решаема. |

## Возможности мастера

- **Показать/скрыть** скрижаль для игроков (значок глаза). Показанная скрижаль сама открывается у игроков, мастер её тоже видит.
- **Назначить** всем игрокам или отдельным.
- **Бросок на помощь**: игрок запрашивает проверку, при успехе открывается подсказка или решается сегмент головоломки. Характеристика или навык выбираются из списка D&D 5e 2024, есть преимущество и помеха, сложность и лимит бросков. Бросок идёт в чат от имени персонажа, сложность игроку не показывается.
- **Таймер**: для любой скрижали. Идёт, пока она открыта игрокам; по истечении скрижаль запирается или сбрасывается. Таймер проверяет клиент мастера.
- **Цепочка**: решённая скрижаль сама открывает следующие, так получаются составные испытания.
- **Редактор**: название, загадка, подсказки, текст награды, настройки каждого типа.
- **Общий экран** (Monk's Common Display и т.п.): кнопка «Общий экран» в окне мастера. Отмеченные учётные записи показывают все открытые скрижали оверлеем поверх страницы, устойчивым к режиму «Скрыть UI».

## Установка

**Через манифест** (после первого релиза):
```
https://github.com/Logan-292/stone-puzzles/releases/latest/download/module.json
```
Вставьте ссылку в Foundry: *Add-on Modules → Install Module → Manifest URL*.

**Вручную:** скачайте `module.zip` из релиза и распакуйте в `Data/modules/stone-puzzles/`.

Затем включите модуль в мире. В панели инструментов сцены (группа токенов) появится кнопка «Каменные скрижали».

## Важно знать

- Ответы на действия игроков считает клиент мастера, поэтому **мастер должен быть в сети**.
- Состояние и решения хранятся в настройках мира: от серверной защиты от подсматривания модуль не защищает.
- Изменение настроек головоломки сбрасывает её прогресс (правка названия, подсказок и броска не сбрасывает).
- Интерфейс только на русском.
- Статус: код проверен синтаксически, логика тестировалась в Node, отрисовка в браузере с заглушкой Foundry. **В живом Foundry v14 с dnd5e и Monk's Common Display** модуль ещё нуждается в проверке, особенно: кнопка в панели сцены, сообщения чата от имени игроков, имена полей dnd5e для бонусов.

## Структура

```
module.json        манифест
scripts/           main (хуки, настройки), logic (игровая логика), store (хранилище, сокеты, броски),
                   views (рендер головоломок, оверлей), editor (окно мастера и редактор), util
styles/stone.css   все стили
```
